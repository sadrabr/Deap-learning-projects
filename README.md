# Deep Learning Projects (Academic Portfolio)

This repository contains a curated set of **deep learning exercises and mini-projects** implemented in Python, mainly as **Jupyter Notebooks**. The work is designed to demonstrate practical competence in building, training, and evaluating neural models with a focus on **reproducible experimentation** and clear methodology.

The notebooks cover end-to-end workflows such as: data preparation, model design, training loops, hyperparameter tuning, and rigorous evaluation.

---

## Key Topics & Skills

- Deep learning fundamentals: **forward/backprop**, optimization, regularization
- Common architectures (depending on notebook):
  - **MLP / Feed-forward networks**
  - **CNNs** for vision-style tasks
  - **Sequence models** (RNN/LSTM) and/or **Transformer-based** pipelines (if included)
- Practical training skills:
  - train/validation split, early stopping, learning-rate scheduling
  - overfitting control (dropout, weight decay)
  - experiment tracking and metric reporting
- Evaluation:
  - classification/regression metrics (e.g., Accuracy, F1, ROC-AUC, MAE/MSE)
  - confusion matrix and error analysis (when applicable)

---

## Repository Structure

Typical contents include:
- Multiple notebooks (e.g., `Exercise *.ipynb`, `*.ipynb`) with self-contained experiments
- Optional supporting files:
  - datasets (or links), helper scripts, saved models, figures

> Note: The repository may evolve over time as new projects are added.

---

## Tech Stack

- **Language:** Python 3
- **Environment:** Jupyter Notebook
- **Frameworks:** PyTorch *or* TensorFlow/Keras (depending on project)
- **Common libraries:** NumPy, Pandas, Matplotlib/Seaborn, scikit-learn
